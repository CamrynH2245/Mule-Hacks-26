# Mule Hacks

Event management web app (PWA) for creating hackathon events and managing their teams, rooms, and mentors.

Stack: Vite + React + TypeScript, React Router, vite-plugin-pwa.

Sign-up collects a name, date of birth, email, phone number, and password. In demo mode, multiple accounts and their salted PBKDF2 password verifiers are saved in this browser's local storage under `mule-hacks-profile`. The Profile tab edits the currently signed-in account and has a notifications bell for pending team invitations, which recipients can accept or decline there or from My teams. The Calendar tab appears below Dashboard and shows the signed-in user's accessible events by date, with month navigation and links to each event workspace; multi-day events appear on every day from their start through end date. The Chats tab groups team General conversations by event and team, with direct/personal conversations in a separate section grouped by event. Selecting a chat opens the selected conversation. Events can be created with a description and start and optional end date and time (to the minute); omitting the end date makes it a one-day event. Event creators can open the cog beside their event in the sidebar to edit its name, description, dates, location, maximum team members (default 5), and maximum teams per person (default 1). Limits count creators and pending invitations and are enforced for team creation, joining, and invitations. Event creators can use the Manage team button above each team card in the event's Teams menu to edit or remove the team, invite registered profiles by email, cancel pending invitations, and remove team members; a separate Add team button creates teams. Event creators can list rooms and workspaces from the Rooms tab; teams claim or release spaces from that same menu, and each space can be claimed by one team. Event descriptions appear on dashboard cards and in event workspaces. The My teams tab lists teams the signed-in user created and teams they belong to; users can join a team by entering its static team code, which is displayed at the bottom of the team workspace. Team creators can invite registered profiles by email; recipients accept or decline invitations from My teams or Profile notifications. Team creators can edit the team name and description together from the Team settings menu; descriptions appear on team cards and in the team workspace. Team creators are automatically assigned the Creator role, can assign members Manager, Leader, Member, or a custom role, and remove other profiles. Members can view team roles and descriptions, use the general chat, and send direct messages to teammates. Team membership, pending invitations, and chat messages are stored in this browser and do not sync across devices. Event creators can share the event's join code, and other accounts in this browser can join from the dashboard; event workspaces appear only for accounts that created or joined them. Event data is stored separately under `mule-hacks-events`; existing events and teams are assigned codes when loaded. This is not server-backed authentication and should not be used to protect real accounts.

When an event creator adds a team, they must assign a different event member as its team creator. The event creator is not automatically added to that team.

## Run locally
    cd web
    npm install
    npm run dev       # dev server
    npm run build && npm run preview   # test PWA/service worker

## Deploy to GitHub Pages
Set the repository's Pages source to **GitHub Actions** in Settings → Pages → Build and deployment. A successful CI run for a push to `main` triggers the Pages deployment; you can also run the Deploy GitHub Pages workflow manually on `main`.
